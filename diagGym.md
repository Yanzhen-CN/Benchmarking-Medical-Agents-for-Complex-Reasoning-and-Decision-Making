                     │  - CALL_TOOL(tool_name) (基本未用)  │
                     │  - ANSWER(final_diagnosis)          │
                     │                                      │

                     └──────────────────┬───────────────────┘

                     ┌────────────────────────────────────┐
                     │             DiagGymEnv              │
                     │  step(action):                      │
                     │   1. parse action                   │
                     │   2. 更新环境状态                   │
                     │   3. 如是 REQUEST → 调用 WM         │
                     │   4. 如是 ANSWER → 结束 episode     │
                     │  ✦ 状态完全由环境自己维护           │
                     └──────────────────┬───────────────────┘
                                        │
                     REQUEST(exam)      │
                         ───────────────▼───────────────
                     ┌────────────────────────────────────┐
                     │             World Model             │
                     │   - 根据 exam 生成结果              │
                     │   - 基于病人 profile + prompt       │
                     │   - 文本生成，非结构化              │
                     │  ✦ 关键缺陷：无真实分布噪声         │
                     └──────────────────┬───────────────────┘
                                        │ exam_result (text)
                                        ▼
                     ┌────────────────────────────────────┐
                     │          Environment State          │
                     │   - 累积 obs / exams / history      │
                     │   - 返回 observation 给 agent       │
                     │  ✦ 历史靠环境保存，非 agent 内部     │
                     └──────────────────┬───────────────────┘
                                        │ obs

                     ┌────────────────────────────────────┐
                     │               Agent                 │
